CARLA remains **assets in the project**, not a running CARLA server.

Sunny-day fluffy clouds: `AClevelandLookDirector` default `SunnyDay` (15:00, volumetric clouds, Epic post). `MidnightRun` is 22:00 + racing bloom for the later photoreal night look.
